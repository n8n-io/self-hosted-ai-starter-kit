# Mirrors that must stay in sync

A value list, id rule or network name that lives in several files changes in all of them in one go. Locate the source and its mirrors before editing. Paths are relative to the repository root; `src/` and `tests/` are short for `packages/cli/src/` and `packages/cli/tests/`.
