# redis-insight

[Redis Insight](https://redis.io/insight/) is the GUI for Redis. Here it inspects the queue-mode redis of the `community` and `enterprise` variants, is served at `redisinsight.<DOMAIN>` and starts on demand from the Tilt UI. Variants: [SPEC.md](../../../SPEC.md#composen8n-variants).

- Homepage: <https://redis.io/insight/>
- Repository: <https://github.com/RedisInsight/RedisInsight>
- Docker image: <https://hub.docker.com/r/redis/redisinsight>
- Documentation: <https://redis.io/docs/latest/develop/tools/insight/>
- Releases: <https://github.com/RedisInsight/RedisInsight/releases>
