# pgadmin

[pgAdmin](https://www.pgadmin.org/) is the web administration tool for PostgreSQL. Here it is preconfigured with the kit's postgres through [server.json](./server.json), served at `pgadmin.<DOMAIN>` and starts on demand from the Tilt UI. Secrets and knobs: [.env.template](./.env.template) and [SPEC.md](../../../SPEC.md#secrets).
