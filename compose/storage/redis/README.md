# redis

[Redis](https://redis.io/) is the in-memory data store n8n uses as the queue-mode broker between main and workers. It is enabled for the `community` and `enterprise` variants, on `n8n-starter-private` only. Variants: [SPEC.md](../../../SPEC.md#composen8n-variants).

- Homepage: <https://redis.io/>
- Repository: <https://github.com/redis/redis>
- Docker image: <https://hub.docker.com/_/redis>
- Documentation: <https://redis.io/docs/latest/>
- API reference: <https://redis.io/docs/latest/commands/>
- Releases: <https://github.com/redis/redis/releases>
