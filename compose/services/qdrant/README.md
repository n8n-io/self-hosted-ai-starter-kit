# qdrant

[Qdrant](https://qdrant.tech/) is a vector database for the embeddings behind n8n's RAG and AI agent workflows. It starts on demand from the Tilt UI and is reachable on `n8n-starter-private` only. Pinned version and knobs: [.env.template](./.env.template).
